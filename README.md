# ФинПоток — Cash-Flow Forecaster

> Понятный прогноз денежных средств для малого бизнеса.
> Streamlit-приложение, которое на основе истории банковских операций
> прогнозирует движение денег на 14–120 дней вперёд, выявляет кассовые
> разрывы (дата, сумма, вероятность) и помогает подготовиться к ним.

streamlit run app.py

# 3. Открыть http://localhost:8501

Приложение запустится в режиме **демо-датасета** — синтетическая выписка

## Модели прогноза (математика)

Прогноз считается **тремя моделями одновременно**. После бэктеста выбирается лучшая по MAE.

### Модель 1: Weekday Mean — «по дням недели»

Идея: у малого бизнеса жёсткий недельный цикл. B2B-оплаты вт-чт, эквайринг растёт к выходным.

Математика:
```python
# Для каждого дня недели d ∈ {0..6}:
net_d = mean(signed_amount | operation_date.dow == d
                              & operation_date >= today - 84 days)
# Клиппинг выбросов на 5/95 перцентилях
lo, hi = quantile(signed_amount, [0.05, 0.95])
net_d = clip(net_d, lo, hi)
# Прогноз:
flow_t = net_d[d_future.dow]
balance_t = balance_{t-1} + flow_t
```

Плюсы: простой, ловит недельные паттерны.
Минусы: не видит долгосрочный тренд.

### Модель 2: Holt Linear (statsmodels)

Идея: экспоненциальное сглаживание с линейным трендом.

Математика:
```python
level_t = α·y_t + (1-α)·(level_{t-1} + trend_{t-1})
trend_t = β·(level_t - level_{t-1}) + (1-β)·trend_{t-1}
forecast_{t+h} = level_t + h·trend_t
# statsmodels: Holt(daily_net, damped_trend=True).fit(optimized=True)
# α, β оптимизируются автоматически по AIC
```

Плюсы: ловит тренд, авто-настройка, damped trend гасит взрыв прогноза.
Минусы: требует ≥14 точек, не учитывает недельную сезонность.

На синтетике C001 Holt обычно выигрывает с MAPE ~1%.

### Модель 3: Linear + Weekday (sklearn)

Идея: гибрид — долгий линейный тренд + недельная поправка.

Математика:
```python
smoothed = daily_net.rolling(7, min_periods=1, center=True).mean()
X = np.arange(len(smoothed)).reshape(-1, 1)
reg = LinearRegression().fit(X, smoothed)
# slope = средний ежедневный рост/падение бизнеса

for i, d in enumerate(future):
    wd = weekday_avg[d.dayofweek]
    trend = intercept + slope · i
    flow = 0.7·wd + 0.3·trend  # 70% сезон, 30% тренд
```

Плюсы: ловит и сезон, и тренд.
Минусы: скользящее среднее сглаживает пики, на зашумлённых данных переоценивает тренд.

### Авто-выбор лучшей модели

Hold-out бэктест: отрезаем последние N=horizon дней, обучаемся без них, прогнозируем, сравниваем с фактом. Считаем MAE/MAPE/RMSE/bias. Лучшая по MAE становится базовой.
```

## Метрики качества

| Метрика | Формула | Интерпретация |
|---|---|---|
| MAE | (1/n)·Σ|y_pred - y_fact| | Средняя абсолютная ошибка в рублях |
| MAPE | (100/n)·Σ|y_pred - y_fact|/|y_fact| | Средняя процентная ошибка |
| RMSE | √((1/n)·Σ(y_pred - y_fact)²) | Штрафует большие ошибки сильнее |
| Bias | (1/n)·Σ(y_pred - y_fact) | Среднее смещение: + завышен, − занижен |

**Интерпретация MAPE:**
- < 5% — отличная точность
- 5–15% — хорошая (типичная для малого бизнеса)
- 15–30% — средняя
- > 30% — плохая, нужны доп. данные

## Доверительные интервалы

Формула:
```
CI_95%(t) = forecast(t) ± 1.96 · σ · √t
```

- σ — стандартное отклонение остатков из бэктеста (= MAE)
- t — номер дня (1, 2, 3, ...)
- 1.96 — z-квантиль для 95% двустороннего интервала
- √t — потому что ошибки накапливаются (как броуновское движение)

Коридор **расширяется со временем** — видно на графике прогноза.

**Вероятность кассового разрыва** = % дней, у которых нижняя граница 95% ниже нуля.
