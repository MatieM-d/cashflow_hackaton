# ФинПоток — MVP

Простой веб-сервис для прогноза денежных средств малого бизнеса на Python + Streamlit.

## Запуск локально

1. Установите Python 3.10 или новее.
2. Распакуйте архив проекта.
3. В терминале в папке проекта выполните:

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Браузер откроет локальное веб-приложение.

## Что умеет MVP
- Загружать CSV-выписку или работать с демо-данными.
- Категоризировать операции по ключевым словам.
- Строить прогноз ежедневного остатка на 30–90 дней.
- Выводить предупреждение при прогнозируемом отрицательном остатке.
- Сравнивать базовый прогноз со стрессовым сценарием.
- Скачать прогноз в CSV.

## Формат CSV
Обязательные колонки: `operation_date`, `amount`, `direction`.
Опциональные: `balance_eod`, `payment_purpose`, `counterparty_name`, `company_id`.
Допускаются заголовки на русском (например, `Дата операции`, `Сумма`, `Направление`, `Остаток`).
Для направления используйте значения вроде `Поступление` и `Списание`.

## Демо-датасет
В проект включён `cashflow_dataset_participants.zip` из предоставленного кейса. Приложение читает файл выбранной компании из архива без распаковки вручную.

## Ограничения
Это прототип. Прогноз использует средний чистый поток по дням недели за последние 12 недель; он не является статистически калиброванной вероятностной моделью. Категоризация основана на ключевых словах. В MVP нет авторизации, постоянного хранения, банковских интеграций и автоматического налогового календаря. Не загружайте реальные конфиденциальные данные в публичный демо-сервер.
